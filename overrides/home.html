// WHAT EVERY REPO GETS

Pinned tools, shared tasks and house policy — mounted once, kept current by Renovate.

Checksum-locked tools

Every CLI is an exact pin in config.toml with per-platform sha256 (and provenance where published) in mise.lock. No tools/go.mod, no linter package.json.

Archetype tasks

common plus exactly one of go, node, python, swift or terraform — each with real fmt, lint, build, test, ci and pr rollups.

A one-line Makefile

include .mise/archetypes/go/include.mk forwards every target to mise run, so make <task> and mise run <task> are interchangeable.

Zero-config house policy

SPDX headers via addlicense, prose via prettier + markdownlint, and workflows via actionlint + zizmor — in every archetype, with house defaults read from .mise/.

Runtime-detected scans

Dockerfiles get hadolint + grype, helm charts and kustomizations get kubescape, scripts get shellcheck — each pass no-ops silently when a repo has none of the files.

Fleet-wide updates

Renovate bumps one pin here and re-locks; release-please cuts a tag; every consumer gets a submodule-bump PR. One commit updates the whole fleet.

// PICK ONE ARCHETYPE

Common first, then exactly one language archetype. They never stack.

go

CLI applications: golangci-lint, govulncheck, gotestsum, GoReleaser and a zensical docs site.

archetypes/go node

Libraries and GitHub Actions on the package.json-script contract — npm, pnpm or bun.

archetypes/node python

uv-native packages and Zensical docs sites: ruff, pytest, uv build.

archetypes/python swift

SwiftPM packages and CLIs: swift format, swift test with coverage, GoReleaser.

archetypes/swift terraform

Modules and environments: init, plan, apply, validate, tflint and terraform-docs.

archetypes/terraform common only

Markdown and YAML repos with nothing to build or test: prose, license and workflow lint.

common

// ONE CONTRACT, EVERY REPO

CI runs make lint, make build and make test — whichever a repo defines.

make help
$ make fmt# auto-fix code + prose, inject license headers
$ make lint# every check-mode pass — the CI gate
$ make test# unit tests with coverage → coverage/
$ make build# the binary, bundle, package or site
$ make ci# exactly what the reusable CI workflow runs
$ make pr# full local gate, then ./commit.sh if present

// THREE STEPS TO ADOPT

01

Mount

Add the library as a submodule at .mise/. mise loads its config natively.

Full guide

02

Wire

Pin the runtime and include common plus one archetype in the root mise.toml; reduce the Makefile to one include.

Run

Format, lint, test and build in one go — the full local gate before every pull request.
